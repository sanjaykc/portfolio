# Profile Image

Please add your professional profile photo to this directory with the filename `profile.jpg`.

## Image Requirements:
- **Filename:** `profile.jpg`
- **Recommended size:** 400x400 pixels or larger (square format)
- **Format:** JPG, PNG, or WebP
- **Quality:** High resolution for best display on retina screens
- **Style:** Professional headshot with good lighting

## Tips for Best Results:
- Use a recent, professional photo
- Ensure good lighting and clear background
- Square crop works best for circular avatar display
- File size should be optimized (under 500KB recommended)

The avatar will be displayed as:
- 88px × 88px on desktop
- 80px × 80px on mobile
- Circular shape with accent border
- Green status indicator (online/available)
- Subtle hover animation

If you don't have a profile image yet, you can use a placeholder or professional avatar service.
