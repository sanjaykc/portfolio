# Portfolio Website

Professional portfolio website for Sanjay Kumar Choudhary, built with plain HTML and CSS for fast, static deployment on GitHub Pages.

## Features

- Responsive single-page portfolio
- Modern glassmorphism-inspired visual design
- Sanitized public-facing professional summary
- Sections for about, skills, experience, education, and contact
- No frameworks, build tools, or external dependencies required

## Deployment

This site is ready to deploy to GitHub Pages at:

`https://username.github.io/portfolio/`

### Steps

1. Push the `portfolio` directory contents to your GitHub repository.
2. Enable GitHub Pages in the repository settings.
3. Set the publishing source to the appropriate branch/folder.
4. Access the deployed site using your GitHub Pages URL.
